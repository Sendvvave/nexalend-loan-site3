# NexaLend demo loan site

A Vercel-ready React/Vite prototype inspired by the supplied orange/black references.

## Pages
- Landing page
- Loan application
- Fictional NexaLend account step
- Demo identity-verification step
- Completion page

## Safety
This prototype deliberately does not reproduce a real bank login or collect real banking credentials. The identity step is clearly marked for sample/demo documents and does not upload files to a server.

## Run
npm install
npm run dev

## Deploy
Import the project into Vercel. The default Vite settings are sufficient.
